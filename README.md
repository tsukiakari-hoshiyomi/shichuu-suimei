# 四柱推命 命式計算キット

生年月日から命式（年柱・月柱・日柱、蔵干、通変星、十二運星、天中殺、大運、年運・月運）を
計算するプログラムです。**鳥海流・天象学会万年暦準拠**。

外部ライブラリは一切使っていません。`meishiki.js` 1枚で動きます。

---

## まず動かしてみる

Node.js（v18以上）が入っていれば、それだけで動きます。

```bash
# 正しく動くか確認する（最初に一度やってください）
node test.js

# 命式を表示してみる
node example.js 1990 8 29 女
```

`node test.js` がすべて ✅ になれば準備完了です。

## コードから使う

```js
import { calcMeishiki } from './meishiki.js';

const m = calcMeishiki(1990, 8, 29, '女');

console.log(m.dayKanshi);              // 丙寅
console.log(m.zoukanTsuuhensei.day);   // 偏印
console.log(m.tenchu.day);             // 戌亥
```

引数は `(西暦, 月, 日, '女' または '男')` の4つです。
性別は**大運の順逆**を決めるためだけに使います。

## 出力の中身

`calcMeishiki()` が返すオブジェクトです。

| キー | 例 | 意味 |
| --- | --- | --- |
| `dayKanshi` / `monthKanshi` / `yearKanshi` | `丙寅` | 各柱の干支 |
| `nikkan` | `丙` | 日干（あなた自身） |
| `zoukan` | `{day:'甲', month:'庚', year:'丁'}` | 各柱の蔵干 |
| `tsuuhensei` | `{month:'偏印', year:'偏財'}` | 通変星（日柱は自分自身なので出ません） |
| `zoukanTsuuhensei` | `{day:'偏印', month:'偏財', year:'劫財'}` | 蔵干通変星 |
| `unsei` | `{day:'長生', month:'病', year:'帝旺'}` | 十二運星 |
| `energy` | `{total:25, day:9, month:4, year:12}` | 運勢エネルギー（十二運星の合計・最大36） |
| `tenchu` | `{day:'戌亥', year:'午未'}` | 天中殺（空亡） |
| `daiunDirection` | `順行` | 大運の進む向き |
| `startingAge` | `3` | 立運（大運が始まる年齢） |
| `daiun` | `[{kanshi, tsuuhensei, unsei, energy}, …]` | 大運8つ分（10年ごと） |
| `chusatsu` | `{seinen, seigetsu, seinichi, hiza, myTC}` | 中殺の判定（真偽値） |

### 年運・月運

```js
import { yearFortune, monthFortune } from './meishiki.js';

yearFortune('丙寅', 2026);          // 2026年から12年分
monthFortune('丙寅', 2026, 8);      // 2026年8月から12ヶ月分
```

それぞれ `{ year, kanshi, stageIndex, mark, label, note }` の配列を返します。
`mark` は `◎◎ ◎ ○ × ×× 天 中 殺` のいずれかです。

### 天中殺のめぐり

```js
import { nextTenchuYears, tenchuMonths } from './meishiki.js';

nextTenchuYears('丙寅', 2026);   // { 天: 2029, 中: 2030, 殺: 2031 }
tenchuMonths('丙寅');            // { 天: 9, 中: 10, 殺: 11 }
```

## ロジックの中身

### 年柱

切り替わりは1月1日ではなく **立春（2月4日ごろ）**。
1月生まれや2月初旬生まれは**前の年**として計算します。

### 月柱

切り替わりは月初ではなく **節入り**（毎月4〜8日ごろ）。
月の干は**五虎遁**（年干から寅月の干を決め、そこから順に振る）で出します。

### 日柱

1900年1月1日を基準に、そこからの日数を六十干支に当てはめます。

### 蔵干

十二支の中に隠れている干です。**柱によってルールが違います。**

| 柱 | ルール |
| --- | --- |
| **日柱** | 支ごとの固定テーブル（日数を見ない） |
| **月柱** | 節入りからの日数で 余気 → 中気 → 本気 と切り替わる。ただし **寅・亥・戌 は余気スキップルール**（月干が余気の干と一致するときだけ余気を採用） |
| **年柱** | **辰・戌 は同五行ルール**（年干と同じ五行の蔵干を採る）。その他は立春からの日数で三正分割 |

日柱の固定テーブルはこうなっています。

```
子=癸  丑=己  寅=甲  卯=乙  辰=戊  巳=丙
午=丁  未=己  申=庚  酉=辛  戌=戊  亥=壬
```

### 通変星

日干から見て、相手の干がどういう関係かで決まります。

| 関係 | 同じ陰陽 | 違う陰陽 |
| --- | --- | --- |
| 同じ五行 | 比肩 | 劫財 |
| 自分が生じる | 食神 | 傷官 |
| 自分が剋す | 偏財 | 正財 |
| 自分を剋す | 偏官 | 正官 |
| 自分を生じる | 偏印 | 印綬 |

**日柱の通変星は出しません。**日干は自分自身なので、必ず比肩になってしまうためです。
日柱については**蔵干通変星**を見ます。

### 十二運星

日干ごとに「長生」の位置が決まっていて、そこから数えます。
陽干は順回り、陰干は逆回りです。

### 天中殺（空亡）

十干は10、十二支は12。組み合わせると支が2つ余ります。この余った2支が天中殺です。
六十干支を10ずつ区切った「旬」ごとに決まります。

| 旬 | 天中殺 |
| --- | --- |
| 甲子〜癸酉 | 戌亥 |
| 甲戌〜癸未 | 申酉 |
| 甲申〜癸巳 | 午未 |
| 甲午〜癸卯 | 辰巳 |
| 甲辰〜癸丑 | 寅卯 |
| 甲寅〜癸亥 | 子丑 |

### 大運

月柱を起点に10年ごと。進む向きは**年干の陰陽と性別**で決まります。

| | 陽年生まれ | 陰年生まれ |
| --- | --- | --- |
| 男性 | 順行 | 逆行 |
| 女性 | 逆行 | 順行 |

立運（始まる年齢）は、節入りまでの日数を3で割った数です（3日＝1年）。

### 年運・月運のバイオリズム

草木の成長になぞらえた**12段階**を十二支に割り当てます。基準は**日柱の天中殺**。

1. 天中殺2支のうち**後ろの支が「殺」**、**前の支が「中」**、**その1つ前が「天」**
2. 「殺」の次の支から、1段階目 → 9段階目が順に並ぶ

```
段階の番号 = (支の番号 − (殺の番号 + 1)) を12で割った余り
  0〜8 … 通常の9段階 ／ 9 = 天 ／ 10 = 中 ／ 11 = 殺
```

年は**年支**、月は**節月の支**で判定します。

**解説文は入っていません。**記号（◎◎ ○ × 天 中 殺）と段階の呼び名だけです。
鑑定書に載せる文章は、ご自身の言葉で用意してください。

## 注意点

### ⚠️ 節入り日は近似です

節気の日付を**固定の表**で持っています（例：立春は2月4日）。
実際の節入りは年によって**1日前後ずれる**ため、**節入り日の前後に生まれた方は
結果が変わる可能性があります**。

正確を期すなら、その年の万年暦で節入り日を確認してください。
より厳密にしたい場合は `SEKKI_APPROX` を実際の節気データに差し替えるのが確実です。

### 三柱です

**時柱は出しません。**鳥海流の運用に合わせて、年柱・月柱・日柱の三柱で計算しています。
出生時刻は使いません。

### 流派によって解釈が変わります

とくに次の3つは流派差が大きい部分です。このキットは**鳥海流・天象学会万年暦**の
やり方で実装しています。他の流派で学んだ方には違って見えることがあります。

- 蔵干の割り振りと日数配分
- 天中殺の呼び方と扱い（算命学の「天中殺」とは体系が別）
- 十二運星の陰陽の回り方

### 対応範囲

**1901年〜2100年**の生年月日に対応しています。

このキットは、実物の鑑定書2件と照合して結果が一致することを確認しています。
